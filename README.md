# WPI Arena


set up web
```zsh
cd web
yarn i
```

build web
```zsh
yarn build
```

set up server (also hosts web)
```zsh
cd server
yarn i
```

build server
```zsh
yarn build
```

create a  `.env` from `.env.example` and fill with API keys, tournament information

run entire system (in server)
```
yarn start
```
